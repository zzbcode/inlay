# Changelog

## 1.1.0

First public open-source release of 夹层 · Inlay.

- Local byte concatenation and extraction, preserving the original Python-compatible format.
- Optional JSON recipes with payload SHA-256, size checks and explicit verification states.
- Chunked checksum progress and cancellation, synthetic examples and local result reuse.
- Empty-result safeguards, keyboard operation and mobile result focus.
- Python reference CLI, JavaScript/Python interoperability coverage and browser workflows.
- Chinese and English documentation, MIT licensing, security reporting and reproducible offline/source archives.

Recipe integrity fields are optional extensions to version 1. Existing recipes without checksums remain readable and are identified as unverified. No metadata is inserted into the combined file.
