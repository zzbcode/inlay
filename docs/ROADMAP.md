# Inlay 路线图 / Roadmap

优先保证文件能够正确还原，再增加便捷功能。路线图表示方向，不是交付日期承诺。

## 首次公开发布已具备 / Included in the first public release

- 原始 `[carrier][payload]` 格式与 Python 兼容。
- 独立 sidecar、可选载荷 SHA-256、明确的校验状态及错误文件拒绝输出。
- 分块摘要、进度、取消、空结果保护、合成示例与生成结果复用。
- 中文/英文说明、格式规范、参考 CLI、贡献与安全政策。
- JavaScript/Python 互通、真实浏览器工作流、可复现离线与源码发布包。

## 后续方向 / Future work

| 方向 / Direction | 用户价值 / Value | 验收边界 / Acceptance boundary |
| --- | --- | --- |
| 大文件流式写出 | 减少浏览器 Blob 与临时存储限制 | 能力检测、分块读写、可取消、不留下冒充完成的文件；逐浏览器公布合成文件实测结果，保留 Blob 回退。 |
| 可选自动识别封装 | 减少说明遗失和手抄 gap | 单独显式模式，定义魔数、长度、版本、文件名与校验；严格校验边界，继续保留原始模式。 |
| 真正的密码加密 | 在本地提供内容保密 | 独立威胁模型与格式；使用受审视的口令派生与认证加密设计；错误口令和篡改拒绝输出；不能声称隐藏文件存在性。 |
| 批量文件与目录 | 一次传递多份材料 | 显式归档、重名与路径穿越保护、解包大小限制，不执行内容。 |
| 可选 PWA | 更方便离线启动 | 只缓存应用资源，默认不缓存用户文件；明确更新和回退行为。 |
| 国际化界面 | 让英文用户直接使用 | 界面、错误、无障碍标签与帮助一起翻译；保持文件名和输出字节不变。 |
| 品牌矢量母版 | 改善小尺寸与主题适配 | 制作可编辑的真正 SVG 母版、单色与浅深色稿，不把 PNG 改扩展名。 |

## 维护原则 / Maintenance principles

1. 新功能不应悄悄改变原始输出；新格式必须显式选择。
2. 文件留在本地，应用保持静态和离线可用。
3. 校验不冒充身份认证，文件隐藏不冒充加密。
4. 新依赖必须有清楚用途、许可与维护成本；不为简单操作引入大框架。
5. 先用合成测试数据证明流程，再讨论性能上限。

账号、云存储、追踪统计和复杂后台不在当前方向内。欢迎通过 issue 提出有具体场景的建议。
