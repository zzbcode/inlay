关于夹层 Inlay

把一份文件追加到另一份文件末尾，需要时按偏移量取回。

  1. 合并：选择载体与隐藏文件，生成后分别下载结果和提取说明。
  2. 保存参数：偏移量 gap 等于原始载体大小。请保留提取说明，避免忘记参数。
  3. 提取：选择合并文件，导入说明，或手动填写 gap 和原文件名（含扩展名）。
这不是密码加密。部分载体追加后可能无法正常打开；压缩、编辑或转码可能丢弃隐藏内容，传输时请发送原文件。新版提取说明包含隐藏文件的 SHA-256，可检查还原内容是否一致；旧说明和手动提取会显示“未校验”。摘要不能证明发送者身份，请通过可信渠道保存提取说明。

兼容原 Python encode / decode 算法；支持旧版叠藏提取说明。文件不会上传或存入浏览器数据库。
